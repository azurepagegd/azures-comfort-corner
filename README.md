--
           AZURE'S COMFORT CORNER - SYSTEM REQUIREMENTS --
=======================================================================

To run the Azure's Comfort Corner modpack smoothly without performance lag, please ensure your launcher setup meets these specifications:

  * Allocated RAM: 12 GB of RAM minimum allocated to the game instance.
  * Required Client Launcher: SKLauncher (Version 4.0 Beta).

You can download the official launcher installer here: https://next.skmedix.pl/downloads

-----------------------------------------------------------------------
HOW TO SET UP IN SKLAUNCHER:
1. Open SKLauncher and navigate to your Instance Settings.
2. Go to the "Java & Memory" panel.
3. Locate the Maximum Memory allocation slider.
4. Set the value to 12288 MB (or 12 GB) before launching the pack.
